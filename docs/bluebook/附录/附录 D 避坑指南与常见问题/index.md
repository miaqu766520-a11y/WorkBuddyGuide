# 附录 D 避坑指南与常见问题

这些坑都是用户用真金白银的积分换来的教训。新手上路前过一遍，能少烧很多积分。

## D.1 十个最常见的坑

1. **提问太笼统，指望它猜心思**——一句「帮我写技术方案」，来回十几轮烧掉大几百积分还是废稿。补齐场景（给谁看）、标准（符合什么规范）、范例（参考框架）后，一次就能过关。
2. **它说「完成了」≠ 真完成了**——涉及具体指标，让它验证后再汇报：「生成完请检查尺寸，告诉我实际尺寸。」
3. **一次给太多信息**——超出上下文的部分会被直接忽略，它不会告诉你漏看了什么。50 页文档请分批给。
4. **出错后它编造理由圆谎**——别轻信解释，让它拿证据：「这个限制有没有官方文档？给链接。」
5. **生成内容不检查直接用**——幻觉永远存在，AI 输出是初稿不是终稿。
6. **积分悄悄烧光**——简单任务用了最贵模式；每天记得领加油站 150 积分。
7. **文件操作不预览就执行**——误删配置文件只要一秒。删/移/改名之前，一定让它先列清单：「先列出要删除的文件清单，我确认后再删。」
8. **只用文字，浪费多模态**——截图表格转 Excel、手写笔记转电子档、发票照片自动录入，都值得试。
9. **空间混用，认知串味**——A 股分析、法律咨询、周报写作混在一个空间，AI 记忆会互相干扰，回答越来越乱。一个主题一个空间。
10. **一次不满意就放弃**——用迭代指令调教：「更简洁」「改正式」「重写第三部分」，别从头再来。

## D.2 出问题先查这几处

::: warning 排错速查
- **AI 不动文件** → 查「设置 → 安全中心 → 文件夹授权」，它只能操作授权过的文件夹
- **Skill 装不上** → 查安装时 Node.js 是否勾选了「添加到系统环境变量」
- **响应越来越慢** → 工作目录别放 C 盘，改到非系统盘
- **记不住事** → 设置 → 记忆 → 打开自动更新开关
- **定时任务不触发** → 电脑得开着，客户端得运行着
:::

## D.3 常见问题 FAQ

**Q：用 WorkBuddy 需要翻墙或自备 API Key 吗？**
不需要。官网下载安装后微信扫码或手机号登录即可使用，也不要求编程基础。

**Q：支持哪些系统？**
Windows 10+ / macOS 12+。Windows 用户建议把安装路径和工作目录都改到非 C 盘。

**Q：Ask、Plan、Craft 三种模式怎么选？**
问问题用 Ask（只动嘴不动文件，最便宜）；要动手且出错代价大（删改文件）用 Plan（先列计划你确认）；标准化任务（周报、文档生成）用 Craft（直接干）。新手先用 Ask/Plan 摸清边界，再上 Craft。

**Q：免费额度够用吗？**
每月自动 500 + 每天加油站 150，免费党每月最多攒 5000 积分；新人别忘了手动领 5000 注册福利。简单问答、文档总结完全够用，重度 Excel/PPT 用户建议参考附录 C 评估订阅。

**Q：为什么 AI 回答越来越乱？**
大概率是空间混用了。每个空间有独立的文件权限、对话历史和记忆，按「个人工作 / 项目 A / 项目 B / 学习研究」分开，左侧边栏顶部切换。

**Q：文件被改乱了能还原吗？**
批量改文件前说一句「帮我创建一个检查点，命名为『XX 前备份』」，玩砸了说「回退到检查点『XX 前备份』」即可一键还原。注意检查点不是永久保存的，重要操作后尽快确认结果。

**Q：它说任务完成了，但结果不对怎么办？**
这是常态不是bug。涉及具体指标的交付，下指令时就要求它验证后汇报，例如「生成完请检查页数和尺寸，告诉我实际数值」。

**Q：积分消耗突然特别快？**
检查三件事：是不是简单任务用了 Craft 模式或最强模型；指令是不是太模糊导致来回多轮；上传的文件是不是没做预处理（空白行列、批注都会烧钱）。
