# 附录 A 常用指令模板

## A.0 指令工程：同样的任务，会写指令的人省 4 倍积分

在抄模板之前，先搞懂高质量指令的公式。这是比任何单个模板都值钱的方法论。

**高质量指令 = 动作 + 目标文件 + 详细要求 + 输出格式 + 保存路径**

```text
读取 @Q2销售数据.csv，按月份汇总销售额，找出最高的前 5 个产品，
生成柱状图和 Top 5 排名表，输出到 ~/reports/Q2_summary.xlsx。
```

对比一下两种写法的成本：

- 「帮我写个方案」→ AI 反复猜，来回 5-6 轮，烧 200-500 积分
- 「帮我写一份[产品名]的推广方案，预算 10 万，面向 25-35 岁白领，3 页 Word」→ 一次到位，50-100 积分

**五条铁律：**

1. 越具体越好——模糊指令 = 浪费积分
2. 分步走——50 页文档一次扔进去，超出上下文的部分直接被忽略
3. 指定输出格式——避免反复改
4. 给它思考空间——「回答前先列出你需要哪些信息，再一步步分析」
5. 不满意就迭代——「更简洁」「改正式」「重写第三部分」，别从头再来

**发指令前 10 秒自检：** 角色？背景？具体动作？输出格式？约束（字数/风格/维度）？验证标准？六项都过，结果不会差。

进阶可以用 CRISPE 框架组织复杂任务：角色（你是一名资深产品经理）+ 背景（我们在做面向中小企业的 SaaS）+ 指令（分析需求优先级）+ 格式（表格，按紧急×重要排列）+ 示例（参考这个格式……）。

::: tip 指令里的 @ 是什么
`@` 是引用本地文件：输入框打 @ 选文件，或直接把文件拖进对话框。
:::

## A.1 文件整理

```text
请整理当前文件夹中的文件。
按文件类型和主题分类，生成新的文件夹结构。
在执行前先给我一个整理方案，不要直接移动文件。
```

## A.2 Excel 分析

```text
请分析这个 Excel 文件。
请输出：核心指标、异常数据、趋势变化、可能原因、建议行动。
请生成一个摘要报告和图表。
```

## A.3 PPT 生成

```text
请根据这份 Word 文档生成一份 PPT 大纲。
要求：10 页左右，每页包含标题、3-4 个要点和建议图表。
风格正式，适合管理层汇报。
```

## A.4 会议纪要

```text
请整理这段会议内容。
输出：会议结论、待办事项、负责人、截止时间、风险点、未决问题。
```

## A.5 行业调研

```text
请调研【行业/公司/产品】。
输出：市场背景、主要玩家、竞品对比、趋势判断、机会点、风险点。
请附上信息来源链接。
```

## A.6 销售方案

```text
请基于客户资料生成一份售前方案。
包括：客户背景、痛点分析、推荐场景、实施路径、预期收益、演示流程。
```

## A.7 信息检索与分析

```text
帮我打开这篇文章并总结核心观点：[URL]
输出格式：核心论点（100 字以内）+ 3 个关键论据 + 我的行动建议。
```

## A.8 代码辅助

```text
帮我写一个 Python 脚本：读取当前目录下所有 CSV 文件，
合并成一个 Excel，每个 CSV 作为一个 sheet 页。
```

## A.9 数据透视分析

```text
请分析 @销售数据.xlsx，按「月份」和「产品类别」做数据透视表，
展示每个月的销售额和同比增长率，结果输出为新的 Excel 文件。
```
